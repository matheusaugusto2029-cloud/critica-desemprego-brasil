# Crítica ao Desemprego Brasileiro

### 📖 Sobre o Projeto
Este é um projeto de página web desenvolvido em HTML e CSS que propõe uma reflexão e análise crítica sobre o cenário do desemprego no Brasil. O objetivo é utilizar o desenvolvimento web como ferramenta de conscientização e debate social.

### 🛠️ Tecnologias Utilizadas
* **HTML5** (Estruturação do conteúdo)
* **CSS3** (Estilização e layout)

### 📈 Status do Projeto & Atualizações Futuras
⚠️ **Este projeto está em constante desenvolvimento.** 

Para as próximas etapas e atualizações planejadas, pretendo adicionar:
* [ ] Responsividade para que o site abra perfeitamente no celular.
* [ ] Gráficos interativos utilizando JavaScript para mostrar dados estatísticos.
* [ ] Seção de artigos e notícias atualizadas sobre o mercado de trabalho.
